# Library contracts

These contracts govern this repository's own contracts and skills. Projects install the contracts under `contracts/`;
they do not install these.

- [Contract naming](001-library-contract-naming/CONTRACT.md): area-first names that carry every technology.
- [Contract format](002-library-contract-format/CONTRACT.md): message, rules, checks, one sentence per line, one allowed form per case, and tool assets wherever a tool can check a rule.
- [Contract generality](003-library-contract-generality/CONTRACT.md): no company, product, or unnamed vendor content, declared maxima, and how a rule's form is chosen.
- [Release versioning](004-library-release-versioning/CONTRACT.md): classified changes and semantic version tags.
- [Skill portability](005-library-skill-portability/CONTRACT.md): self-contained, licensed skills with Agent Skills metadata and no private tooling.
